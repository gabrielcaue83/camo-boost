# CAMO//BOOST

Landing page de um serviço de boost de camuflagens para Warzone (Ouro, Platina, Harmonic Break e Divergência).

Vite + GSAP (ScrollTrigger, SplitText) + Lenis + Three.js.

- **Hero** com topografia militar em WebGL
- **Preloader** com a arma 3D passando pelas camos
- **Vitrine** interativa com camos em shader e painel de mestria
- **Como funciona** com rota tracejada
- **Preços**: radar além do horizonte sobre a Coreia em nuvem de pontos que termina dentro da loja 3D

```bash
npm install
npm run dev
```

Projeto de fã, sem vínculo com Activision ou Call of Duty. Preços e textos são provisórios.
